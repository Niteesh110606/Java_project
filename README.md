# Sliding Puzzle Game - Challenge Your Mind! 🧩

- A Java Swing-based sliding puzzle game where players rearrange image tiles to solve the puzzle.
- Features customizable images, timing, pause/resume functionality, and reset options.

---

##  About the Game

- Rearrange scrambled image tiles on a 4x3 grid to restore the original picture.
- Load your own images or use the default one.
- Engage in a fun challenge with timing and control features.

---

##  Features

- **Load and resize images** for full customization.
- **4x3 grid layout** for a balanced puzzle experience.
- **Shuffle tiles** to generate random puzzle configurations.
- **Detect puzzle completion** instantly.
- **Timer with pause/resume** to track your solving time.
- **Reset button** to start fresh with a new scramble.
- **Choose images from your filesystem** for personalized puzzles.

---

## 🛠️ Built With

- **Java SE** (Swing for GUI)
- **Java ImageIO and AWT** (for image processing)
